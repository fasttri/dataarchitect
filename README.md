# Data Architect Projects

This repository contains a collection of projects developed during the Data Architect Nanodegree Program. Each project focuses on different aspects of data architecture, including database design, data warehousing, ETL processes, and data governance.

## Projects Overview

### 1. HR Database Design

- **Description**: Designed and implemented a relational database for the Human Resources department of an imaginary company. The project involved creating entity-relationship diagrams (ERDs) and building the database schema to manage employee information efficiently.

- **Contents**:
  - `HR_DB_Final/`: Contains SQL scripts for database creation and data insertion.
  - `ERD_Diagrams/`: Includes conceptual, logical, and physical ERD diagrams.

### 2. Data Warehousing with Snowflake

- **Description**: Developed a data warehousing solution using Snowflake. The project encompassed designing the architecture, staging data, creating an Operational Data Store (ODS), and building a Data Warehouse (DWH) to analyze the effect of weather on restaurant reviews.

- **Contents**:
  - `ingestion_to_snowflake/`: Scripts and configurations for data ingestion into Snowflake.
  - `StagingToODS_snowflake/`: Processes to move data from staging to ODS.
  - `ODStoDWH_snowflake/`: Transformation scripts to populate the Data Warehouse.
  - `Correlations_snowflake/`: Analytical queries to study data correlations.

### 3. Big Data Systems

- **Description**: Designed an enterprise Data Lake system to handle large volumes of data. The project included creating a Data Lake architecture, developing ETL processes, and ensuring scalable data storage and retrieval.

- **Contents**:
  - `SolutionHive/` and `SolutionHive2/`: Hive scripts and configurations for data processing.
  - `Basic ETL/`: ETL scripts for data extraction, transformation, and loading into the Data Lake.

### 4. Data Governance

- **Description**: Implemented data governance strategies to ensure data quality, metadata management, and master data management. The project focused on establishing policies and procedures for effective data management within an organization.

- **Contents**:
  - `DataGovernancePolicies/`: Documentation of data governance frameworks and policies.
  - `MetadataManagement/`: Tools and scripts for managing metadata.
